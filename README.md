# Wizard Runner 🧙‍♂️

An open-source runner for your libraries — formerly *Library Runner*.

Wizard Runner is a lightweight, community-driven project for running and managing libraries with a little bit of magic. Contributions, issues and ideas are welcome.

## Getting started

```bash
git clone https://github.com/Workerant-max/Wizard-runner-.git
cd Wizard-runner-
```
